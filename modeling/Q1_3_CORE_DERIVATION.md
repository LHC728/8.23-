# Q1(3) CORE-2 推导与最小验证

设 `a=1/(100 sqrt(3))`。在目标处，程序由原始 `atan2` 角的偏导动态推导出

```text
D_B f_B = [[ a,   0], [-a/2, -1/200]]
D_C f_B = [[ 0,   0], [-a,        0]]
D_C f_C = [[ a,   0], [-a/2,  1/200]]
D_B f_C = [[ 0,   0], [-a,        0]]
```

隐函数给出本机精确最佳响应的交叉导数：

```text
dB+/dC = [[0, 0], [-2/sqrt(3), 0]]
dC+/dB = [[0, 0], [ 2/sqrt(3), 0]]
```

完整 B/C 周期的一阶乘积为零矩阵，谱半径为 0。这只说明精确、局部、非退化最佳响应的线性化收缩；不自动涵盖有限差分实现，也不构成全局收敛证明。

本项目的自动微分复核使用独立前向双数内核，有限差分复核使用中心差分；三路没有插入预审数值。联合 Jacobian 复算得到 `|det J|=8.3333333333e-10`、最小奇异值 `0.0025640096 m^-1`、条件数 `4.3910671`。六台后续接收机的最差最小奇异值为 `0.0064584730 m^-1`，最大条件数为 `2.3609770`。

负对照中，仅 FY00/FY01 的一个夹角约束秩为 1，只能给出一维等角轨迹，不能启动二维归槽；它不是可行 Baseline。
