# Q1(3) 正式结果

## 状态

    Q1_3_PROGRAM_GATE = PASS
    RESULT_SCOPE = 表 1、目标邻域、非退化、确定性回放

## 固定调整方案

FY00 与 FY01 始终不动。执行 5 个 FY04/FY07 宏周期：FY00、FY01、FY07 发射时仅 FY04 以本机 OBA/OBC 调整；FY00、FY01、FY04 发射时仅 FY07 以本机 OCA/OCB 调整。之后固定四锚 FY00/FY01/FY04/FY07 共同发射，六台其余无人机以各自两条预装主角并行归槽。

六机的期望主角和四条 holdout 角完全由理想目标槽位与理想四锚预计算。在线控制器只处理本机残差和局部试探位移；表 1 真值仅由 observation plant 保存，最终 evaluator 不回灌控制器。

## 程序证据

| 检查 | 实际证据 |
| --- | --- |
| 三路 B/C 导数 | 解析、自动微分、有限差分最大差小于 2e-6 |
| 独立精确 oracle | 解析-Jacobian Newton；不调用有限差分控制器；B/C 目标邻域回放 PASS |
| 六机预装签名 | 每机 2 条主角、4 条 holdout，均由理想槽位/理想锚计算 |
| 六机 holdout | 每机四条实际残差均不超过 1e-6 rad，逐机记录于 JSON |
| 机械信息防火墙 | 控制器真值/坐标/锚点输入字段数为 0；跨机角输入数为 0；evaluator 回灌为 false |
| 排程 | 每轮含 FY00、外围发射机不超过 3、接收机不发射、发射机固定 |
| 表 1 最终半径误差 | 1.954e-7 m |
| 表 1 最大相邻圆心角误差 | 2.421e-9 rad |
| 表 1 最大目标位置误差 | 2.935e-7 m |
| 完整旋转/镜像蜕变 | 覆盖 FY04/FY07、六机跟随者及全部 10 节点；逐点与最终指标均比较 |
| 同口径消融 | FY04/FY07 与 FY02/FY05 均报告完整最佳响应周期的谱半径、联合秩、条件数 |

本次验证器加固将防火墙、排程、预装签名、独立 oracle、蜕变和消融全部改为可失败的确定性检查：实际 replay 事件记录每个动作、观测接收机与坐标快照；AST 和故障注入检查非法字段、非法排程和 oracle 对有限差分控制器的错误调用。JSON 保存每项原始数值、阈值和负对照结果。

机器可读证据：results/q1_3/q1_3_program_gate.json，由 python -m tests.q1_3_program_gate 生成。

## 结论边界

结果只支持表 1 的目标邻域、非退化确定性回放；不支持全局收敛、全局唯一或任意初态恢复。超出局部域、遇到退化或 holdout 不通过时必须拒绝。
