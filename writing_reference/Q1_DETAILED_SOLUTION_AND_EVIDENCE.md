## 2. 统一符号与纯方位观测

### 2.1 符号

| 符号 | 含义 | 可否作为在线输入 |
|---|---|---|
| $p_i$ | 第 $i$ 架无人机在仿真世界中的真实位置 | 否，只供观测生成和离线评估 |
| $q_i$ | 第 $i$ 架无人机的理想目标槽位内部坐标 | 可预装目标关系，但绝对坐标不作为实时观测 |
| $x$ | 当前待定位接收机的位置变量 | 未知量 |
| $h_{ab}(x)$ | 接收机 $x$ 看发射机 $a,b$ 的无符号夹角 | 是，由该接收机本机测得 |
| $U_r$ | 编号 $r$ 的目标槽位局部域 | 可作为预装的局部判定范围 |
| $F_i$ | 第 $i$ 架接收机用本机角构造的残差 | 是 |
| $J_i$ | 本机角残差对本机移动坐标的 Jacobian | 由本机试探估计或离线解析复核 |

### 2.2 为什么夹角写成 atan2 形式

设接收机位于 $x$，两架发射机位于 $p_a,p_b$。定义

$u=p_a-x,\qquad v=p_b-x.$

二维叉积记为

$u\times v=u_xv_y-u_yv_x,$

则本机无符号夹角为

$h_{ab}(x) = \mathrm{atan2} \left( \left|u\times v\right|, u^{\mathsf T}v \right) \in[0,\pi].$

解释如下：

- 点积 $u^{\mathsf T}v$ 描述两个方向有多同向；
- 叉积绝对值 $|u\times v|$ 描述两个方向张开的程度；
- 同时使用二者可以区分锐角、直角和钝角；
- 取叉积绝对值后，观测不依赖顺时针或逆时针方向，因此属于无符号夹角。

该式比只使用

$\arccos\frac{u^{\mathsf T}v}{\|u\|\,\|v\|}$

更适合数值实现，但它不能消除 $0$、$\pi$、收发机重合和近共线本身的几何退化。

**依据性质：** 点积、叉积和夹角关系属于解析几何基本关系；本题的具体观测式由题意独立建立。文献 [1] 只提供“角约束是否足以固定位置必须检查可辨识性”的理论背景。

### 2.3 夹角梯度

对两个固定点 $A,B$，令

$s=(A-x)\times(B-x),\qquad d=(A-x)^{\mathsf T}(B-x).$

在 $s\ne0$ 且接收机不与发射机重合的区域，有

$\nabla h_{AB}(x) = \mathrm{sign}(s) \frac{d\nabla s-s\nabla d}{d^2+s^2},$

其中

$\nabla s=(A_y-B_y,\ B_x-A_x),$

$\nabla d=-\left[(A-x)+(B-x)\right].$

这个梯度回答的是：“接收机沿横向或纵向移动一点，所测夹角会怎样变化？”它是后续 Jacobian、局部可辨识性和本机试探控制的共同基础。

**依据性质：** 对本题观测式直接求导；程序中另用有限差分或自动微分交叉复核。

## 3. Q1(1)：三架已知发射机下的定位

### 3.1 本问要回答什么

FY00 与另外两架编号已知、位置无偏差的外围无人机发射信号。某架接收机利用自己测得的三个两两夹角，建立位置模型。

关键困难不是“能不能写出三个方程”，而是：

- 无符号夹角可能产生镜像分支；
- 圆与圆可能有零个、一个或多个交点；
- 三个角不自动保证全平面唯一；
- $0$、$\pi$、相切、近共线和收发机重合会退化。

### 3.2 一个夹角为什么对应圆弧

两架发射机位于 $A,B$，接收机 $X$ 测得

$\angle AXB=\theta, \qquad 0<\theta<\pi.$

记弦长

$D=\|A-B\|.$

根据圆周角定理和弦长关系，候选圆半径为

$\rho=\frac{D}{2\sin\theta}.$

令弦中点为

$M=\frac{A+B}{2},$

取与 $B-A$ 垂直的单位向量

$e_{\perp} = \frac{1}{D} \begin{bmatrix} -(B_y-A_y)\\ B_x-A_x \end{bmatrix}.$

圆心到弦中点的距离为

$d_{\perp}=\rho|\cos\theta|.$

两个候选圆心为

$O_{+}=M+d_{\perp}e_{\perp},\qquad O_{-}=M-d_{\perp}e_{\perp}.$

因此，一个夹角约束首先给出弦两侧的圆分支，而不是一个点。由于同一圆上不同弧段可能对应 $\theta$ 或 $\pi-\theta$，圆交点还必须代回原始 $\mathrm{atan2}$ 观测式过滤。

**依据性质：** 圆周角定理和弦长公式；无需外部算法假设。

### 3.3 三个角如何形成完整候选集

设三架已知发射机为 $A,B,C$，接收机观测为

$y= \begin{bmatrix} y_{AB}\\ y_{AC}\\ y_{BC} \end{bmatrix}.$

理论方程为

$h_{AB}(x)=y_{AB},\qquad h_{AC}(x)=y_{AC},\qquad h_{BC}(x)=y_{BC}.$

不能只选前两个角、只取某一侧圆、再接受求解器返回的第一个根。冻结实现执行以下完整流程：

1. 对 $AB$、$AC$、$BC$ 三条角约束分别生成双侧定夹角圆分支；
2. 遍历任意两条角约束；
3. 对每一对圆分支保留全部圆—圆交点；
4. 删除与发射机重合的非法点；
5. 合并数值容差内的重复点；
6. 将每个候选代回全部三条原始角；
7. 只有三条角都满足容差的候选才保留。

因此输出是集合

$\mathcal C(y) = \left\{ x:\ h_{AB}(x)=y_{AB},\ h_{AC}(x)=y_{AC},\ h_{BC}(x)=y_{BC} \right\},$

而不是被强制选择的单点。

第三条角的作用是同一接收机内部的分支筛选。它不是来自外部实验的独立验证。

### 3.4 局部唯一性如何判定

从三个角中选择在目标点附近局部独立的两个分量，例如

$G(x)= \begin{bmatrix} h_{AB}(x)-y_{AB}\\ h_{AC}(x)-y_{AC} \end{bmatrix}.$

其 Jacobian 为

$J(x)=DG(x).$

若在编号 $r$ 的理想槽位 $q_r$ 满足

$\mathrm{rank}\,J(q_r)=2,$

并且局部槽位域 $U_r$ 中恰有一个完整候选，则可依据反函数定理作出局部唯一性判定。

通俗解释：位置有横、纵两个自由度。秩为 2 表示两个角对这两个移动方向都有独立反应；秩不足则至少有一个方向无法从这些角中识别。

必须注意：

- 满秩只给局部正则性，不给全局唯一性；
- 如果局部域中有多个候选，应保留候选或拒绝；
- 局部域半径必须有证据，不能随意扩大。

### 3.5 Q1(1) 的确定性结果

| 检查 | 正式结果 | 说明 |
|---|---:|---|
| 非退化真值找回 | PASS | 找回样例点 $(1.5,1.0)$ |
| 镜像分支 | PASS | 同时保留 $(0,1)$ 与 $(0,-1)$ |
| 三角回代 | PASS | 每个保留候选都复现三条原始角 |
| 独立数值复核 | PASS | 多初值阻尼 Gauss--Newton 与圆构造根集一致 |

### 3.6 Q1(1) 最终结论

> 对三架编号已知、位置无偏差的发射机，利用双侧定夹角圆生成全部有限候选，再用第三条本机角回代。只有当编号对应的局部槽位域中恰有一个候选且 Jacobian 满秩时，才能判定接收机在该局部域内唯一定位；否则输出候选或拒绝。

### 3.7 理论与文献支撑边界

- 圆半径、圆心和交点关系由圆周角定理直接得到；
- 局部满秩到局部可逆由反函数定理支持；
- 文献 [4]、[6] 说明三控制点角度反演可能多解，从而支持“完整候选优先”的决策；
- 不能迁移 P3P 的三维姿态方程、四次方程或具体解数。

## 4. Q1(2)：匿名发射机的最少数量

### 4.1 本问新增了什么困难

FY00、FY01 的身份已知，额外发射信号的编号未知。此时未知量不再只有连续位置 $x$，还包括一个离散编号 $b$。

所以本问不能把“匿名编号”当作普通测量误差，而必须同时回答：

- 匿名信号是谁发出的；
- 接收机位于哪里；
- 现有信息是否足以把不同编号假设分开。

### 4.2 为什么零架额外发射机一定不足

若只有 FY00、FY01 发射，接收机只有一个标量观测

$h_{01}(x)=y_{01}.$

它的等值集是一条定夹角圆弧，二维位置仍有一个连续自由度。因此

$m_{\min}>0.$

正式反例中，FY02 目标点

$(76.6044,64.2788)$

与另一点

$(74.2681,65.5508)$

产生完全相同的

$h_{01}=1.22173048\ \mathrm{rad}.$

这不是算法失败，而是观测信息本身不足。

### 4.3 增加一架匿名发射机后的联合模型

接收机编号为 $r\in\{2,\ldots,9\}$。匿名发射机不能是接收机自己，因此合法编号集合为

$\mathcal B_r = \{2,\ldots,9\}\setminus\{r\}.$

对每个编号假设 $b\in\mathcal B_r$，定义三维纯方位观测向量

$\Phi_b(x) = \begin{bmatrix} h_{01}(x)\\ h_{0b}(x)\\ h_{1b}(x) \end{bmatrix}.$

观测顺序由匿名令牌固定，而不是先知道编号后重排。

所有局部身份—位置联合解为

$\mathcal S_1(y) = \bigcup_{b\in\mathcal B_r} \left\{ (b,x):\Phi_b(x)=y,\ x\in U_r \right\}.$

求解步骤为：

1. 枚举全部合法编号 $b$；
2. 对每个 $b$ 调用 Q1(1) 完整候选器；
3. 保留所有编号—几何分支，不取首根；
4. 对每个候选回代全部三条原始角；
5. 检查候选是否位于本机局部槽位域；
6. 检查正确编号映射的 Jacobian 是否满列秩；
7. 检查不同编号假设的观测集合是否有正分离裕度；
8. 证据不足则拒绝，不强选编号。

### 4.4 几何局部证书

正确编号下，$\Phi_b$ 的 Jacobian 是 $3\times2$ 矩阵：

$D\Phi_b(x) = \begin{bmatrix} \nabla h_{01}(x)\\ \nabla h_{0b}(x)\\ \nabla h_{1b}(x) \end{bmatrix}.$

若

$\mathrm{rank}\,D\Phi_b(q_r)=2,$

则正确编号下的位置映射在目标点附近能感知二维位移。三行中至少存在两行组成非奇异的二维主观测分量组合。

正式有限枚举得到：

$\min\sigma_{\min} =0.002159555653\ \mathrm{m}^{-1} =\frac{0.2159555653}{R},$

以及最佳 $2\times2$ 子式的最小绝对行列式

$8.816349035\times10^{-6}\ \mathrm{m}^{-2} =\frac{0.08816349035}{R^2}.$

这些正数说明理想槽位处所有合法组合均局部满列秩，但仍不能证明全平面没有远根。

### 4.5 编号局部可辨识性判据

只满秩还不够，因为另一个错误编号也可能在别处产生相似角度。需要检查不同编号假设的观测像集是否分开。

定义局部编号观测分离度

$\Delta_{\mathrm{id}}(U_r) = \min_{b\ne b'} \mathrm{dist} \left( \Phi_b(U_r), \Phi_{b'}(U_r) \right).$

如果

$\Delta_{\mathrm{id}}(U_r)>0,$

则在该局部域内，不同编号假设的可产生观测之间留有正间隔。

实际计算采用保守 Lipschitz 下界。若局部域半径为 $\rho_U$，则

$\mathrm{dist} \left( \Phi_b(U_r), \Phi_{b'}(U_r) \right) \ge \left\| \Phi_b(q_r)-\Phi_{b'}(q_r) \right\| -\rho_U(L_b+L_{b'}),$

其中 $L_b,L_{b'}$ 是相应角映射在局部域内的梯度上界。

本题理想槽位的最小编号观测分离度为

$20^\circ=0.3490658504\ \mathrm{rad}.$

取 $1\ \mathrm m$ 的确定性示例局部域时，保守下界为

$0.2783389151\ \mathrm{rad}>0.$

这里的 $1\ \mathrm m$ 只是用于展示正分离证书的确定性示例，不是题目给出的偏差上限，也不是全局定理。

### 4.6 完整枚举证据

| 项目 | 正式结果 |
|---|---:|
| 接收机数量 | 8 |
| 每个接收机的真实匿名编号情形 | 7 |
| 每个观测需要检验的编号假设 | 7 |
| 生产枚举器实际假设事件 | $8\times7\times7=392$ |
| 正确局部样例找回 | 56/56 |
| 全部保留的身份—几何候选 | 350 |
| 1 m 局部域内错误编号候选 | 0 |
| 完整保存的远端或错误编号候选 | 294 |

294 是所有枚举情形累计得到的远端或错误候选记录，不表示单次定位会同时出现 294 个答案。保留它们正是为了避免把局部结论伪装成全局唯一。

### 4.7 为什么理论最少数量是 1

必要性：$m=0$ 只给一条圆弧，所以不充分。

局部充分性：$m=1$ 时，在自身编号已知、目标邻域、非退化和扰动小于分离裕度的条件下，完整编号枚举、局部满秩和正观测分离度共同允许联合判定编号与位置。

所以允许的结论是

$\boxed{m_{\min}=1}$

但必须紧接着写明“局部、非退化、自身编号已知且角扰动足够小”。

### 4.8 第二匿名发射机的角色

如果 $m=1$ 的分离裕度不足或观测落在边界，操作层可以增加第二个匿名令牌。此时对两个令牌的全部有序编号排列进行枚举：

$7\times6=42.$

每个排列都要回代六个原始两两夹角。正式样例找回正确有序编号 $(3,4)$。

第二架的角色是“证据不足时的冗余发射备用方案”，不是理论最少数量。

### 4.9 Q1(2) 最终结论

> 零架额外发射机不能确定二维位置；在接收机知道自身编号、位于目标局部域、发射几何非退化且角扰动小于编号分离裕度时，增加一架编号未知但位置无偏差的发射机，经过全编号—全几何分支枚举即可实现编号与位置的联合局部可辨识。因此局部理论最少数量为 1；证据不足时增加第二架作为冗余备用。

### 4.10 理论与文献支撑边界

- $m=0$ 不足由定夹角圆弧反例直接证明；
- $m=1$ 局部充分由本题有限枚举、反函数定理和有限集合正分离共同支持；
- 文献 [3] 支持把匿名方位分为离散身份与连续几何两层；
- 文献 [5] 说明错误关联会产生虚假交点，支持完整枚举与一致性筛选；
- 文献中的贝叶斯滤波、高斯门限、运动信息和绝对方位均未迁移。

## 5. Q1(3)：表 1 圆形编队的多轮调整

### 5.1 目标构型

以 FY00 为圆心

$O=q_0=(0,0),$

令 FY01 固定目标相位，半径为

$R=100\ \mathrm m.$

九架外围机的理想槽位可在内部坐标中写为

$q_k = R \begin{bmatrix} \cos\dfrac{2\pi(k-1)}9\\ \sin\dfrac{2\pi(k-1)}9 \end{bmatrix}, \qquad k=1,\ldots,9.$

这只是内部建模坐标。在线控制器不会读取自己的世界坐标。

FY00 和 FY01 是题给可信种子：

$O=(0,0),\qquad A=q_1=(100,0).$

只有 $O,A$ 发射时，任一接收机仍只有一个夹角约束，位置落在一条圆弧上，无法直接二维归槽。因此要先建立更多可信锚点。

### 5.2 第一阶段：FY04 与 FY07 双节点交替校正建锚

选取

$B=\mathrm{FY04},\qquad C=\mathrm{FY07}.$

理想位置为

$B^\star=(-50,50\sqrt3),\qquad C^\star=(-50,-50\sqrt3).$

一个宏周期有两个子轮：

| 子轮 | 固定发射机 | 唯一接收并移动者 | 本机主约束角 |
|---|---|---|---|
| 1 | FY00、FY01、FY07 | FY04 | $\angle OBA,\angle OBC$ |
| 2 | FY00、FY01、FY04 | FY07 | $\angle OCA,\angle OCB$ |

每个子轮都包含 FY00，只使用两架外围发射机，接收机不在发射集合中，发射机在接收机试探与移动期间固定。

FY04 的本机残差为

$f_B(B;C) = \begin{bmatrix} \angle OBA-\pi/6\\ \angle OBC-\pi/6 \end{bmatrix}.$

FY07 的本机残差为

$f_C(C;B) = \begin{bmatrix} \angle OCA-\pi/6\\ \angle OCB-\pi/6 \end{bmatrix}.$

两个残差向量中的角都由对应接收机自己测量。FY04 不读取 FY07 的角，FY07 也不读取 FY04 的角。

### 5.3 目标点附近为什么适合交替调整

令

$a=\frac{1}{100\sqrt3}.$

在理想位置处，对本题夹角式独立求导得到

$D_Bf_B = \begin{bmatrix} a&0\\ -a/2&-1/200 \end{bmatrix}, \qquad D_Cf_B = \begin{bmatrix} 0&0\\ -a&0 \end{bmatrix},$

$D_Cf_C = \begin{bmatrix} a&0\\ -a/2&1/200 \end{bmatrix}, \qquad D_Bf_C = \begin{bmatrix} 0&0\\ -a&0 \end{bmatrix}.$

$D_Bf_B$ 和 $D_Cf_C$ 均可逆，表示另一节点暂时固定时，两条本机角在目标附近足以确定本机的二维修正。

将 $B$ 对固定 $C$ 的精确局部根记为 $B^+(C)$。由隐函数定理，

$\frac{\partial B^+}{\partial C} = -\left(D_Bf_B\right)^{-1}D_Cf_B = \begin{bmatrix} 0&0\\ -2/\sqrt3&0 \end{bmatrix}.$

同理，

$\frac{\partial C^+}{\partial B} = -\left(D_Cf_C\right)^{-1}D_Bf_C = \begin{bmatrix} 0&0\\ 2/\sqrt3&0 \end{bmatrix}.$

一个完整宏周期的一阶误差传播矩阵为

$M = \frac{\partial C^+}{\partial B} \frac{\partial B^+}{\partial C} =0_{2\times2}.$

因此

$\rho(M)=0<1.$

这里 $\rho(M)$ 是谱半径。小于 1 表示目标附近的一阶误差收缩；等于 0 表示精确最佳响应宏周期的一阶误差项被消去。

这个结论的范围非常重要：

- 它是目标点附近的一阶局部结论；
- 它对应每个子轮充分求到本机局部根的精确最佳响应；
- 它不等于有限差分小步必然一步归零；
- 它不证明任意初态全局收敛；
- 它不证明 FY04/FY07 对所有可能排程全局最优。

联合 Jacobian 的正式指标为

$|\det J|=8.3333333333\times10^{-10},$

$\sigma_{\min}(J)=0.0025640096\ \mathrm m^{-1}, \qquad \kappa(J)=4.3910671.$

解析导数、自动微分与中心有限差分三路最大差小于 $2\times10^{-6}$。

### 5.4 在线控制器怎样在不知道坐标时移动

每架移动接收机拥有两条本机正交执行轴 $e_1,e_2$。它先沿每条轴进行正、负小幅试探，并用本机角残差估计 Jacobian：

$\widehat J_i[:,\ell] = \frac{ F_i(u_i+\delta e_\ell) -F_i(u_i-\delta e_\ell) }{2\delta}, \qquad \ell=1,2.$

这里：

- $u_i$ 是无人机自己的局部动作坐标；
- $\delta$ 是试探距离；
- $F_i$ 只由该机自己的角残差组成；
- $\widehat J_i$ 描述沿两条本机执行轴移动时角残差的变化。

随后计算阻尼最小二乘步：

$\Delta u_i = -\eta \left( \widehat J_i^{\mathsf T}\widehat J_i+\lambda I \right)^{-1} \widehat J_i^{\mathsf T}F_i.$

其中：

- $\eta$ 是步长系数；
- $\lambda$ 是阻尼，防止 Jacobian 条件较差时动作过大；
- 还要配合限步和本机残差回溯；
- $\delta,\eta,\lambda$ 是算法参数，不是题给物理参数。

在线控制器只能看到本机残差和试探历史。世界坐标、锚点真实坐标和离线评估结果不进入该公式的在线输入。

### 5.5 第二阶段：固定四锚，六机并行归槽

完成五个 FY04/FY07 宏周期后，固定

$T=\{\mathrm{FY00},\mathrm{FY01},\mathrm{FY04},\mathrm{FY07}\}.$

这正好是 FY00 加三架外围发射机，满足题目上限。

六架其余无人机的两条主约束如下：

| 接收机 | 两条本机主约束角 |
|---|---|
| FY02、FY03 | $h_{OA},h_{OB}$ |
| FY05、FY06 | $h_{OB},h_{OC}$ |
| FY08、FY09 | $h_{OA},h_{OC}$ |

四个锚点固定后，六架接收机之间不互相提供角度，也不互相影响发射点，因此六个二维调整问题可以并行执行。

每架无人机的目标主约束角和另外四条留出角约束，都由“理想目标槽位 + 理想四锚”预先计算。禁止根据 FY04/FY07 调整后的实际坐标重新生成目标角，否则会把实际锚误差偷偷吸收到目标中。

六机局部映射的最坏指标为

$\min\sigma_{\min}=0.0064584730\ \mathrm m^{-1},$

$\max\kappa=2.3609770.$

每机两条主角用于移动，另外四条同机角只作留出角约束检验。留出角仍来自同一接收机，所以它是同源检查，不是独立外部实验。

### 5.6 最终验收

所有在线动作结束后，离线评估器才读取真实坐标。验收至少包括：

1. 九架外围机到 FY00 的半径误差；
2. 相邻外围机的圆心角与 $2\pi/9$ 的偏差；
3. 各机相对于编号目标槽位的位置误差；
4. 排程是否合法；
5. 留出角残差是否超过阈值；
6. 是否发生拒绝或局部分支失败。

定义最大半径误差

$E_R = \max_{k=1,\ldots,9} \left| \|p_k-p_0\|-100 \right|.$

定义最大相邻圆心角误差

$E_\theta = \max_{k=1,\ldots,9} \left| \angle p_kp_0p_{k+1}-\frac{2\pi}{9} \right|,$

其中编号按圆周顺序循环。

表 1 确定性回放得到：

| 指标 | 正式数值 |
|---|---:|
| 最大半径误差 | $1.954\times10^{-7}\ \mathrm m$ |
| 最大相邻圆心角误差 | $2.421\times10^{-9}\ \mathrm{rad}$ |
| 最大目标位置误差 | $2.935\times10^{-7}\ \mathrm m$ |
| 每机四条留出角残差 | 均不超过 $10^{-6}\ \mathrm{rad}$ |

这些数值只说明理想数学模型下的表 1 确定性回放成功，不代表现实无人机具备微米精度。

### 5.7 Q1(3) 的独立与机械验证

| 验证 | 检查什么 | 能支持什么 |
|---|---|---|
| 解析、自动微分、有限差分三路导数 | 四个导数块是否一致 | 局部导数实现可信 |
| 独立解析基准求解器 | 不调用在线有限差分控制器仍能找回局部根 | 主控制器不是唯一证据来源 |
| 信息隔离 AST 与负对照 | 非法真值字段、坐标读取或评估器调用能否被拒绝 | 在线信息边界得到机械检查 |
| 排程事件日志与故障注入 | 每轮是否含 FY00、接收机是否误发射 | 排程确实执行而非文字承诺 |
| 几何不变性检验 | 平移、旋转、镜像后动作和几何结果是否保持对应 | 算法依赖角关系而非隐藏绝对坐标 |
| 同口径对照试验 | FY04/FY07 与其他双节点组合比较局部谱、秩和条件数 | 当前组合在目标点的局部选择有证据 |
| 离线半径与圆心角验收 | 最终是否形成目标正九边形 | 回答题目最终几何要求 |

### 5.8 Q1(3) 最终结论

> 固定 FY00、FY01，先执行五个 FY04/FY07 严格本地双节点交替校正宏周期；随后固定 FY00、FY01、FY04、FY07 四锚，让其余六架无人机只依靠各自预置的本机目标角并行调整。该方案在表 1、目标邻域和非退化的确定性回放中恢复半径 100 m 的正九边形，并满足发射排程与禁止跨机角汇总的要求。

允许写“目标邻域确定性回放成功”和“精确最佳响应周期的一阶谱半径为零”；禁止写“任意初态全局收敛”“现实飞行达到微米精度”或“FY04/FY07 对所有排程全局最优”。

## 6. 三问共同的失败与拒绝规则
