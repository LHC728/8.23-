## 0. 先读结论

第二问的最终方案是：

> 用 FY11、FY15 两架可信且保持不动的无人机提供长度为 $4d^\ast$ 的尺度基线；再让 FY04、FY03 只依据各自测得的夹角交替移动，建立四参考机框架；最后固定 FY03、FY04、FY11、FY15，使其余 11 架无人机分别利用本机测得的六个夹角完成并行归槽。

这里的 $d^\ast>0$ 是目标锥形编队中相邻无人机的共同间距。如果需要把题目中的示例取为 50 m，则令 $d^\ast=50\ \mathrm{m}$，可信基线长度为 $4d^\ast=200\ \mathrm{m}$。

必须同时写清以下边界：

- FY11、FY15 是可信无偏差种子，这是经用户批准的附加条件，不是原题明示条件；
- 该基线只固定共同尺度，整体平移、旋转和镜像仍然自由；
- 在线控制器不读取世界坐标、距离、仿真真值或其他接收机测得的夹角；
- 现有证据只支持目标邻域、非退化几何和确定性回放，不支持任意初态全局收敛；
- 可信种子一旦存在偏差，误差会传播，不能声称模型对参考机偏差稳健。

## 1. 原题要求与建模难点

原题要求为 15 架无人机设计锥形编队的位置调整方案，使三族直线上的相邻无人机间距相等，并继续遵守纯方位无源定位的信息条件。

本问有四个真正的数学难点：

1. 夹角在共同缩放下不变，只靠静态纯夹角不能确定指定的物理尺度；
2. 三架参考机提供的角约束可能出现多个几何分支，方程数量够不等于位置唯一；
3. 参考框架本身也需要由严格本机信息建立，不能汇总不同接收机测得的角；
4. 分阶段局部成功不自动等于最终 15 机编队成功，必须验收实际控制终态。

方位刚性和角度网络定位文献同样指出，方位或角约束通常保留规范自由度，锚点数量与几何非退化性会影响可定位性 [1-3]。不过，本题的观测是“同一接收机处两架发射机连线的夹角”，不是文献中的绝对方位或相对方位向量，因此下面的具体公式、排程和数值结论均由本题重新推导与验证。

## 2. 目标锥形编队

### 2.1 参数化目标格点

把图 3 的 15 架无人机排成 5 行。令行号为 $c=0,1,2,3,4$，第 $c$ 行的列号为 $j=0,1,\ldots,c$。定义内部目标坐标

```math
q_{c,j}=d^\ast
\begin{bmatrix}
-\sqrt{3}c/2\\
j-c/2
\end{bmatrix}.
```

编号按从上到下、每行从一侧到另一侧依次对应 FY01 至 FY15。于是

```math
\begin{aligned}
\mathrm{FY01}&\leftrightarrow q_{0,0},\\
\mathrm{FY02},\mathrm{FY03}&\leftrightarrow q_{1,0},q_{1,1},\\
\mathrm{FY04},\mathrm{FY05},\mathrm{FY06}&\leftrightarrow q_{2,0},q_{2,1},q_{2,2},
\end{aligned}
```

其余编号按同样规则继续排列。

这个坐标系只是研究者用于推导目标角的内部坐标，不代表无人机在线知道自己的绝对位置。

### 2.2 为什么所有相邻边都等长

格点中三种相邻位移分别是

```math
\Delta q_1=d^\ast
\begin{bmatrix}0\\1\end{bmatrix},
\qquad
\Delta q_2=d^\ast
\begin{bmatrix}-\sqrt{3}/2\\-1/2\end{bmatrix},
\qquad
\Delta q_3=d^\ast
\begin{bmatrix}-\sqrt{3}/2\\1/2\end{bmatrix}.
```

三者的模长均为

```math
\|\Delta q_1\|=\|\Delta q_2\|=\|\Delta q_3\|=d^\ast.
```

所以该参数化自动满足图 3 中三族直线上相邻无人机间距相等。离线评估时，共检查 30 条最近邻边和 12 条至少包含两点的最大格点直线。

## 3. 统一纯方位观测

设接收机位置为 $x$，两架发射机位置为 $p_a,p_b$，并令

```math
u=p_a-x,
\qquad
v=p_b-x.
```

接收机能够测得的无符号夹角定义为

```math
h_{ab}(x;p_a,p_b)
=
\mathrm{atan2}\!\left(
\left|u\times v\right|,
u^{\mathsf T}v
\right)
\in[0,\pi].
```

其中二维叉积为标量

```math
u\times v=u_xv_y-u_yv_x.
```

这条公式的含义是：点积判断两个方向偏向同向还是反向，叉积绝对值刻画张开程度，二者共同确定 $0$ 到 $\pi$ 的夹角。由于取了叉积绝对值，观测没有顺时针或逆时针符号。

## 4. 为什么必须单独处理尺度

对所有位置作共同相似变换

```math
p_i'=sRp_i+t,
\qquad
x'=sRx+t,
\qquad
s>0,
```

其中 $R$ 是旋转或反射矩阵，$t$ 是平移向量。变换后

```math
p_a'-x'=sR(p_a-x),
\qquad
p_b'-x'=sR(p_b-x).
```

点积和叉积绝对值都乘以 $s^2$，所以

```math
h_{ab}(x';p_a',p_b')=h_{ab}(x;p_a,p_b).
```

因此，纯夹角不能区分间距 $d^\ast$ 和 $2d^\ast$。这个结论与方位刚性理论中的共同尺度自由度一致 [1]。

本项目采用的尺度条件为：

```math
\|q_{11}-q_{15}\|=4d^\ast.
```

FY11、FY15 是已知编号、位置无偏差且保持不动的可信种子。它们不需要向其他无人机广播绝对坐标；其作用只是让真实构型中存在一条正确的长度基线。

该假设的性质必须准确表述：

- 文献支持“如果要固定尺度，就需要合法尺度信息”；
- 文献不负责证明“FY11、FY15 天然无偏差”；
- FY11、FY15 的具体选择来自本题有限排程比较；
- 可信种子假设是模型输入条件，而不是程序算出的结果。

## 5. 三阶段位置调整方案

### 5.1 阶段一：固定两架可信种子

固定 FY11 和 FY15。它们在后续排程中只发射、不移动。

四个关键目标槽位为

```math
\begin{aligned}
q_{11}&=(-2\sqrt{3},-2)d^\ast,\\
q_{15}&=(-2\sqrt{3},2)d^\ast,\\
q_4&=(-\sqrt{3},-1)d^\ast,\\
q_3&=(-\sqrt{3}/2,1/2)d^\ast.
\end{aligned}
```

前两个点提供尺度，后两个点将通过本机角观测建立出来。

### 5.2 阶段二：FY04 与 FY03 交替建立参考框架

记

```math
A=\mathrm{FY11},\qquad
B=\mathrm{FY15},\qquad
C=\mathrm{FY04},\qquad
D=\mathrm{FY03}.
```

一个宏周期包含两轮。

#### 第一轮：FY04 接收和移动

FY11、FY15、FY03 发射，只有 FY04 接收和移动。FY04 的目标三维纯方位观测向量为

```math
\Phi_C^\ast=
\begin{bmatrix}
\pi/2\\
5\pi/6\\
\pi/3
\end{bmatrix},
```

其分量顺序为 $h_{11,15}$、$h_{11,3}$、$h_{15,3}$。选择两项主残差

```math
F_C(C;D)=
\begin{bmatrix}
h_{11,15}(C)-\pi/2\\
h_{15,3}(C)-\pi/3
\end{bmatrix}.
```

剩余的

```math
h_{11,3}(C)-5\pi/6
```

作为同一接收机的留出角约束检验。它可以检查分支或异常，但不能称为独立外部观测。

#### 第二轮：FY03 接收和移动

FY11、FY15、FY04 发射，只有 FY03 接收和移动。FY03 的目标观测向量为

```math
\Phi_D^\ast=
\begin{bmatrix}
\mathrm{atan2}(2\sqrt{3},1)\\
\mathrm{atan2}(\sqrt{3},6)\\
\pi/2
\end{bmatrix},
```

其分量顺序为 $h_{11,15}$、$h_{11,4}$、$h_{15,4}$。选择

```math
F_D(D;C)=
\begin{bmatrix}
h_{11,15}(D)-\mathrm{atan2}(2\sqrt{3},1)\\
h_{11,4}(D)-\mathrm{atan2}(\sqrt{3},6)
\end{bmatrix},
```

并把

```math
h_{15,4}(D)-\pi/2
```

作为同机留出角约束检验。

每轮发射机在接收机试探和移动期间保持不动。FY04 不使用 FY03 在另一轮测得的角，FY03 也不使用 FY04 测得的角。

### 5.3 本机微小试探与阻尼最小二乘更新

每架接收机只知道“我执行某个本机二维动作后，我自己测得的两个主夹角怎样变化”。对本机两个动作轴 $e_1,e_2$ 作对称微小试探，估计动作到角残差的 Jacobian：

```math
\widehat J_i[:,\ell]
=
\frac{
F_i(u_i+\delta e_\ell)-F_i(u_i-\delta e_\ell)
}{2\delta},
\qquad \ell=1,2.
```

然后计算阻尼最小二乘动作

```math
\Delta u_i
=
-\eta
\left(
\widehat J_i^{\mathsf T}\widehat J_i+\lambda I
\right)^{-1}
\widehat J_i^{\mathsf T}F_i.
```

其中：

- $\eta$ 是增益，用于避免一步修正过猛；
- $\lambda$ 是阻尼，用于缓解 Jacobian 接近病态时的数值放大；
- $\delta$ 是本机可执行的微小试探步长；
- 最大动作长度限制过大位移；
- 回溯只接受使本机主残差下降的动作。

归一化计算采用

```text
probe = 2e-4 d*
gain = 0.9
damping = 1e-7
max_step = 0.25 d*
backtracking factors = 1, 1/2, 1/4, 1/8, 1/16, 0
```

这些数值是已冻结实现参数，不应在论文写作阶段另行手工修改。

### 5.4 建锚为什么在目标附近可行

在目标点定义四个 Jacobian 块

```math
J_C=\frac{\partial F_C}{\partial C},
\qquad
B_C=\frac{\partial F_C}{\partial D},
\qquad
J_D=\frac{\partial F_D}{\partial D},
\qquad
B_D=\frac{\partial F_D}{\partial C}.
```

在 $d^\ast=1$ 的归一化坐标下，解析结果为

```math
J_C=
\begin{bmatrix}
-1/2&\sqrt{3}/6\\
-1/4&\sqrt{3}/4
\end{bmatrix},
\qquad
B_C=
\begin{bmatrix}
0&0\\
1/2&-\sqrt{3}/6
\end{bmatrix},
```

```math
J_D=
\begin{bmatrix}
-14/39&-2\sqrt{3}/39\\
-4/13&2\sqrt{3}/39
\end{bmatrix},
\qquad
B_D=
\begin{bmatrix}
0&0\\
1/2&-\sqrt{3}/6
\end{bmatrix}.
```

一般 $d^\ast$ 下四个矩阵均再乘 $1/d^\ast$。两个本机 Jacobian 均可逆。由隐函数关系，FY04 和 FY03 的局部最佳响应导数分别为

```math
F=-J_C^{-1}B_C=
\begin{bmatrix}
-1&\sqrt{3}/3\\
-\sqrt{3}&1
\end{bmatrix},
```

```math
G=-J_D^{-1}B_D=
\begin{bmatrix}
3/4&-\sqrt{3}/4\\
-7\sqrt{3}/4&7/4
\end{bmatrix}.
```

直接相乘得到

```math
GF=0_{2\times2}.
```

按状态顺序 $(C,D)$，一个完整宏周期在目标点的一阶 Jacobian 为

```math
D\mathcal T_\ast=
\begin{bmatrix}
0&F\\
0&GF
\end{bmatrix}
=
\begin{bmatrix}
0&F\\
0&0
\end{bmatrix}.
```

因此

```math
(D\mathcal T_\ast)^2=0,
\qquad
\rho(D\mathcal T_\ast)=0.
```

联合残差 Jacobian

```math
K=
\begin{bmatrix}
J_C&B_C\\
B_D&J_D
\end{bmatrix}
```

满足

```math
\det K=\frac{1}{117(d^\ast)^4}>0.
```

这说明目标点附近不存在连续局部退化，并且完整周期的一阶误差传播为幂零结构。它只支持“目标附近的一阶局部收缩”，不能解释成“非线性系统两轮精确到位”或“任意初态全局收敛”。

### 5.5 阶段三：四参考机下 11 架无人机并行归槽

建锚完成后固定

```math
\mathcal A_4=\{\mathrm{FY03},\mathrm{FY04},\mathrm{FY11},\mathrm{FY15}\}.
```

四架参考机同时发射。每架剩余无人机只在自己的接收位置形成六维纯方位观测向量

```math
\Phi_i(x)=
\begin{bmatrix}
h_{3,4}(x)\\
h_{3,11}(x)\\
h_{3,15}(x)\\
h_{4,11}(x)\\
h_{4,15}(x)\\
h_{11,15}(x)
\end{bmatrix}.
```

四架发射机产生六个两两夹角，但这六个角都属于同一接收机，不会跨接收机交换。

离线根据理想格点预装目标向量

```math
\Phi_i^\ast=\Phi_i(q_i).
```

目标值为 $0$ 或 $\pi$ 的分量位于无符号角的边界，不进入普通光滑 Jacobian。对其余分量，从所有二元组合中选择最不容易放大误差的两项：

```math
S_i^\ast
=
\mathop{\arg\max}_{|S|=2}
\sigma_{\min}\!\left(J_{i,S}(q_i)\right).
```

$\sigma_{\min}$ 是最小奇异值。它越大，两个动作方向越容易被角变化区分。几何布局会影响纯方位定位的可观测性和误差放大，因此不能只按角的数量选参考关系 [4-6]。

六个分量的索引顺序为：

| 索引 | 本机夹角 |
|---:|---|
| 0 | $h_{3,4}$ |
| 1 | $h_{3,11}$ |
| 2 | $h_{3,15}$ |
| 3 | $h_{4,11}$ |
| 4 | $h_{4,15}$ |
| 5 | $h_{11,15}$ |

正式实现选择的两项主观测为：

| 接收机 | 主观测索引 | 两项主观测 |
|---|---|---|
| FY01 | 1, 4 | $h_{3,11},h_{4,15}$ |
| FY02 | 1, 4 | $h_{3,11},h_{4,15}$ |
| FY05 | 2, 4 | $h_{3,15},h_{4,15}$ |
| FY06 | 0, 4 | $h_{3,4},h_{4,15}$ |
| FY07 | 4, 5 | $h_{4,15},h_{11,15}$ |
| FY08 | 1, 4 | $h_{3,11},h_{4,15}$ |
| FY09 | 1, 5 | $h_{3,11},h_{11,15}$ |
| FY10 | 1, 5 | $h_{3,11},h_{11,15}$ |
| FY12 | 3, 4 | $h_{4,11},h_{4,15}$ |
| FY13 | 1, 4 | $h_{3,11},h_{4,15}$ |
| FY14 | 1, 2 | $h_{3,11},h_{3,15}$ |

其余非边界角全部用于同机回代、错误分支拒绝和异常检查。每架无人机使用与建锚阶段相同的本机有限差分与阻尼最小二乘控制器，因此 11 架无人机之间没有在线耦合，可以在参考机固定后并行调整。

## 6. 为什么要保留完整几何候选

### 6.1 一个定夹角约束产生两侧圆分支

设两架固定发射机为 $A,B$，接收机测得

```math
\angle AXB=\theta,
\qquad
0<\theta<\pi.
```

令

```math
L=\|B-A\|,
\qquad
M=\frac{A+B}{2},
\qquad
n=\frac{1}{L}
\begin{bmatrix}
-(B_y-A_y)\\
B_x-A_x
\end{bmatrix}.
```

由圆周角定理，两侧候选圆的半径和圆心可写为

```math
r=\frac{L}{2\sin\theta},
\qquad
O_{\pm}=M\pm\frac{L}{2\tan\theta}n.
```

正负号覆盖弦两侧分支。由于无符号角还可能出现补角和镜像混淆，任何圆交点都必须代回原始 $\mathrm{atan2}$ 观测式，而不能只取求解器返回的第一个根。

### 6.2 完整候选器的步骤

对每架接收机执行：

1. 对每个非边界夹角生成双侧定夹角圆；
2. 枚举任意两项活动角及其全部圆分支；
3. 保留全部圆-圆交点，不采用首根规则；
4. 单列相切圆、重合圆和连续解族；
5. 排除接收机与发射机重合的点；
6. 用全部非边界本机角逐候选回代；
7. 去重并输出完整有限候选集；
8. 再用不调用圆候选器的过定多初值数值复核器比较根集合。

三信标机载定位文献同样指出，三信标条件下仍可能多解，增加第四信标可用于消歧 [3]。本项目没有直接移植文献的世界坐标定位算法，而是把这一几何警示落实为“四参考六角、完整分支、全角回代”。

## 7. 排程为什么选择 FY11/FY15、FY04/FY03

设计阶段离线比较了

```math
\binom{15}{2}\times13\times12=16380
```

个“两个可信种子加两个有序建锚节点”的排程。比较指标包括：

1. 建锚角是否避开 $0$、$\pi$ 和收发机重合；
2. 两个本机 Jacobian 是否满秩；
3. 完整宏周期谱半径是否小于 1；
4. 最终四参考组能否为 11 个槽位生成完整单候选；
5. 最坏 Jacobian 最小奇异值、条件数和角边界裕度；
6. 独立根求解器是否与生产候选器一致。

数量筛选结果为：

| 层级 | 排程数 |
|---|---:|
| 理论有序排程 | 16380 |
| 几何可计算 | 8820 |
| 局部收缩 | 3690 |
| 最终四参考完整可用 | 2880 |

FY11/FY15 到 FY04/FY03 的排程是在同口径有限比较后选出，不是凭编号直觉指定。旧参考组 $\{2,6,8,14\}$ 在 FY11 槽位检测到两个根，说明完整候选器确实能够拒绝表面上看似可行的参考组。

## 8. 在线算法流程

### 8.1 离线预装

离线可以使用目标格点完成以下工作：

1. 生成各接收机的目标纯方位观测向量；
2. 固定发射/接收排程；
3. 为每架跟随者选定两项主观测；
4. 保存剩余同机角作为留出角约束；
5. 保存阈值、试探步长、增益、阻尼和最大步长。

离线坐标只用于生成这些预装常量，不能成为在线动作函数的输入。

### 8.2 在线调整伪代码

```text
输入：可信种子、固定排程、各机目标角、控制参数

固定 FY11、FY15

重复执行建锚宏周期：
    FY11、FY15、FY03 发射
    FY04 用本机两项主角做对称试探、阻尼更新和回溯
    FY11、FY15、FY04 发射
    FY03 用本机两项主角做对称试探、阻尼更新和回溯
    若两机主残差及各自留出角均通过阈值，则停止建锚

固定 FY03、FY04、FY11、FY15

对其余 11 架无人机并行执行：
    读取本机六个夹角中的预定分量
    用本机两项主角做对称试探
    计算阻尼最小二乘动作
    限步并回溯
    用其余同机非边界角检查分支和异常
    通过阈值后停止；证据不足则拒绝，不伪装成功

离线评估实际 15 节点终态的 30 条边和 12 条直线
输出：调整排程、最终状态和适用边界
```

## 9. 信息边界

| 信息 | 在线控制器可用 | 说明 |
|---|---|---|
| 本机编号 | 是 | 用于选择预装目标角和排程 |
| 当轮发射机编号 | 是 | 排程已知 |
| 本机测得的夹角 | 是 | 只能由测得它的接收机使用 |
| 本机动作和试探历史 | 是 | 用于估计动作-角响应 |
| 预装目标角、阈值和参数 | 是 | 由理想构型离线生成 |
| 世界绝对坐标 | 否 | 只供仿真观测生成和离线评估 |
| 距离测量 | 否 | 控制器不读取距离 |
| 其他接收机测得的夹角 | 否 | 禁止交换或集中汇总 |
| 仿真真值、候选根、评估器输出 | 否 | 不能回灌动作计算 |
| 未来状态 | 否 | 每步只用当前及本机历史信息 |

FY11、FY15 的可信基线是环境条件，不等于把基线距离读数送进每架在线控制器。

### 10.2 实际端到端验证

端到端 Gate 不把 FY03、FY04 重置到理想坐标，而是把有限试探得到的实际建锚终点直接传给 11 架跟随者控制。共运行 33 个确定性案例，其中 32 个为非零扰动，扰动半径为

```math
0.02d^\ast,
\quad
0.05d^\ast,
\quad
0.10d^\ast,
\quad
0.20d^\ast,
```

每个半径使用 8 种方向模式，13 架移动无人机均受到非零扰动。

| 实际终态指标 | 最坏值 | 验收阈值 |
|---|---:|---:|
| 节点误差 | $2.27\times10^{-7}d^\ast$ | $2.00\times10^{-6}d^\ast$ |
| 边长误差 | $2.70\times10^{-7}d^\ast$ | $4.00\times10^{-6}d^\ast$ |
| 边长相对标准差 | $1.17\times10^{-7}$ | 作为离散度记录 |
| 最大共线距离 | $7.43\times10^{-8}d^\ast$ | $2.00\times10^{-6}d^\ast$ |
| 最大同机留出角残差 | $1.17\times10^{-7}$ rad | $2.00\times10^{-6}$ rad |

33/33 个案例全部通过。最慢情形为 $r=0.20d^\ast$、方向模式 7，建锚用了 14 个宏周期，单架跟随者最多执行 10 次控制动作。

### 10.3 负对照与边界证据

- 把实际 FY03/FY04 终点替换为理想锚点时，锚点来源审计会报错；
- 人为扰动最终位置时，30 边和 12 线验收会失败；
- 伪造真值字段或跨接收机角字段时，信息防火墙会拒绝；
- 给可信参考机加入 $0.001d^\ast$ 或 $0.01d^\ast$ 偏差时，严格端到端阈值均不通过；
- $0.30d^\ast$ 和 $0.40d^\ast$ 压力域出现 2 个失败，明确限制结论范围。

## 11. 论文支撑与迁移边界

| 文献 | 支撑的判断 | 本题实际采用 | 明确不采用 |
|---|---|---|---|
| Zhao 与 Zelazo [1] | 纯方位约束保留平移和尺度自由度，刚性取决于结构 | 尺度自由度审计、几何非退化意识 | 有向方位、近全局控制律、通信图协议 |
| Jing、Wan 与 Dai [2] | 角数量不等于唯一定位，锚点和角可固定性重要 | 锚点条件、完整候选和局部秩检查 | 集中 SDP、网络角汇总 |
| Advani 与 Weile [3] | 三信标定位可能多解，第四信标可消歧 | 四参考六角与全部分支回代 | 已知世界坐标的机载位姿恢复 |
| 刘忠 [4] | 观测数量足够仍可能因几何退化不可观测 | 共线、边界和 Jacobian 秩检查 | 动态多时刻模型与速度状态 |
| 孙文涵、鲜斌 [5] | 锚点结构影响纯方位编队唯一性和漂移 | 参考框架与自由度说明 | Leader 绝对位置、连续动力学和 Lyapunov 结论 |
| 吴龙文等 [6] | 几何布局与角误差影响纯角定位精度 | 最小奇异值、条件数和角残差评价 | 绝对 AOA、双站位置和其具体估计公式 |

文献支持的是“为什么必须检查尺度、锚点、多解和几何退化”。FY11/FY15、FY04/FY03 的编号选择、零谱关系、11/11 单候选和全部正式数值，均来自本题自己的推导、有限枚举和程序 Gate，不能写成文献直接给出的结论。

## 12. 允许和禁止的论文结论

### 12.1 允许写

> 在 FY11、FY15 为已知编号且位置无偏差的可信种子、二者基线为 $4d^\ast$、FY04/FY03 位于目标局部域、每轮发射机保持不动且角几何非退化的条件下，FY04/FY03 的严格本机交替调整在目标点具有一阶零谱结构；建立 FY03/FY04/FY11/FY15 四参考框架后，其余 11 个目标槽位在完整本机角观测下均为单候选，并在认证局部域的确定性端到端回放中完成等边、共线的锥形编队调整。

### 12.2 禁止写

- 原题明示 FY11、FY15 无偏差；
- 没有尺度参考也能恢复指定 $d^\ast$；
- 任取三架或四架参考机都唯一；
- 任意初态全局收敛；
- 一阶零谱等价于非线性两轮精确到位；
- 参考机存在偏差也不影响结果；
- 仿真精度等价于现实飞行精度；
- 世界平移、旋转和镜像已经恢复。
