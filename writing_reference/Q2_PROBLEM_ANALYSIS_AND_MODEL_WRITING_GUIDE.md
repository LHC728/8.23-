## 1. 最终写法选择

### 1.1 问题分析的最佳组合

Q2 的“问题分析”最适合组合以下写法：

1. 学习 2018 B334：先指出真正需要解决的结构困难，再解释为什么选当前抽象；
2. 学习 2015 B340：预告可观测信息、变量、方法衔接和验证路径；
3. 学习 2019 B057：每次只增加一个必要条件，形成自然递进；
4. 学习 2020 B125：让后续阶段复用同一状态和观测内核，不每节重新起灶。

因此，Q2 的分析主线应为：

> 锥形等边格点目标 → 纯夹角的尺度不可辨识 → 加入最小可信基线 → 本机交替建锚 → 四参考下并行归槽 → 端到端验收与结论边界。

这不是“基线模型、改进模型、创新模型”的机械堆叠，而是一条由信息缺口推动的机制递进。

### 1.2 模型建立与求解的最佳结构

Q2 不宜把所有公式集中写完，再在后面单独堆算法名。最适合的结构是：

> 共用几何内核先定义一次；每个阶段就地写“目标、观测、残差、更新、停止与输出”；最后统一写完整候选、端到端验证和适用范围。

它综合了：

- 2018 B334 的“共同基础模型加分阶段扩展”；
- 2018 B217 的“形式化约束负责完整性，工程算法负责可执行性”；
- 2017 B264 的“模型完整式、可读步骤、结构图和结果表分层表达”；
- 2016 B044 的控制变量验证；
- 2016 B022 的异常与反例不隐藏。

### 2.1 最适合 Q2 的问题分析结构

建议用四段，不要在“问题分析”里提前展开全部 Jacobian。

#### 第一段：从题目目标转成数学目标

应说明：

- 图 3 可以写成 15 点三角格点；
- 目标不是恢复某个绝对世界坐标，而是使三族相邻边等长；
- 需要同时设计合法观测、调整排程和成功判据。

#### 第二段：指出尺度不可辨识

应说明：

- 平移、旋转、镜像和共同缩放不改变夹角；
- 因而纯夹角只能确定相似形状，不能自行产生指定长度；
- 若要指定 $d^\ast$，必须说明尺度信息从哪里来；
- 本文采用经批准的 FY11/FY15 可信基线，而不是偷用所有无人机的距离。

#### 第三段：指出参考框架和多解问题

应说明：

- 只有两架可信种子时，不能直接让所有跟随者唯一归槽；
- 先由 FY04/FY03 严格本机交替建锚；
- 三参考可能多解，因此最终使用四参考六角并保留全部候选；
- 参考机的选择来自完整有限比较，不是人工挑编号。

#### 第四段：预告求解与验证

应说明：

- 本机对称试探估计动作-角 Jacobian；
- 阻尼最小二乘、限步和回溯给出动作；
- 用解析 Jacobian、独立求根、负对照和实际端到端终态验收；
- 结论仅限可信基线、目标邻域和非退化情形。

### 2.2 可直接改写的“问题分析”示范稿

> 锥形编队可抽象为具有三族等距边的 15 点三角格点，因而本问不仅要给出目标槽位，还要确定在纯方位信息边界内可执行的发射、接收与移动顺序。接收机只能利用自己测得的发射机两两夹角，不能读取距离、世界坐标或其他接收机的角。
>
> 纯夹角在整体平移、旋转、镜像和共同缩放下保持不变，因此若完全没有尺度参考，只能恢复相似队形，不能指定相邻间距 $d^\ast$。为消除尺度不可辨识性，本文采用 FY11、FY15 两架可信无偏差种子提供长度为 $4d^\ast$ 的基线；该条件只固定尺度，不固定世界位姿。
>
> 仅有两架种子仍不足以直接完成全部归槽，且三个参考点下可能存在多个满足角约束的位置分支。为此，先让 FY04 与 FY03 在两种固定发射排程下只使用各自角度交替校正，建立 FY03/FY04/FY11/FY15 四参考框架；随后每架跟随者独立使用四参考机形成的六个本机夹角，选取条件最好的两个分量控制，其余同机角用于分支拒绝和异常检查。
>
> 求解时通过本机微小试探估计动作-角响应矩阵，再用阻尼最小二乘、限步和回溯产生移动。模型可信度由解析 Jacobian 与有限差分对照、完整候选与独立多初值求根、错误参考组负对照以及实际 15 节点端到端终态验收共同支撑。故本文结论限定在可信基线、目标邻域和非退化几何范围内。

这段可以压缩或拆分，但不得删掉“尺度条件不是题目明示”和“只支持局部结论”。

## 5. 公式怎样摆放

### 5.1 一个公式段的完整顺序

每个重要公式建议采用：

1. 先说这条关系解决什么问题；
2. 定义新符号、索引和取值域；
3. 单独居中放公式；
4. 公式后逐项解释；
5. 写成立条件或退化情形；
6. 说明怎样求解或进入下一步；
7. 必要时给小例或验证。

例如，不要直接丢出阻尼最小二乘式。应先写：“为了只利用本机试探获得可执行动作，我们先估计动作-角 Jacobian，再求解带阻尼的局部最小二乘修正。”然后放公式，再解释 $\eta,\lambda,\delta$。

### 5.2 Markdown 排版规范

- 行内只放短符号，例如 `$d^\ast$`、`$h_{ab}$`；
- 矩阵、分式、长等式单独使用 `math` 代码块；
- 公式块前后留空行；
- 不在 Markdown 标题中放公式；
- 不在表格单元格中放多行矩阵；
- 使用 `\mathrm{atan2}`，不要使用当前渲染器不允许的 `\operatorname`；
- 避免未配对的 `\left` 和 `\right`；
- 集合可直接写 `\{\cdots\}`，不要写损坏的 `\left{`；
- 不用手工空格把公式编号推到右侧。

推荐写法：

````markdown
由相似变换不改变夹角，可得

```math
h_{ab}(x';p_a',p_b')=h_{ab}(x;p_a,p_b).
```

因此，静态纯夹角不能单独确定共同尺度。
````

### 5.3 最终 Word 论文的公式编号

```text

```

不要靠连续空格对齐。正文引用写“由式（1）可知”，不要写“由上式可知”，因为分页后“上式”可能不再位于上方。

## 6. 引用怎样摆放

### 6.1 学术引用放在哪里

引用应紧跟它实际支撑的判断，例如：

> 方位约束通常保留共同尺度自由度，锚点和约束图结构会影响编队的可定位性 [1-2]。

接着再写本题自己的推导：

> 对本题夹角函数作相似变换，可直接得到式（3）。

不要把 `[1]` 孤零零放在显示公式末尾，让读者误以为本题的具体 FY 编号、目标角和矩阵来自文献。

### 6.2 哪些内容需要引文

需要引用：

- 方位刚性和尺度自由度的一般理论；
- 锚点与可定位性的普遍关系；
- 三信标定位可能多解、第四信标可消歧的学术背景；
- 纯方位可观测性和几何退化的一般结论。

不需要外部引文，但需要指向本项目证据：

- 图 3 的内部坐标参数化；
- FY11/FY15、FY04/FY03 的具体编号选择；
- 16380 个排程和筛选数量；
- $GF=0$、$1/117$；
- 11/11 单候选；
- 33/33 端到端结果；
- 所有正式误差数字。

这些内容应写“由本文推导”“由完整枚举得到”或“见表 X 和支撑材料”，不能伪装成文献结论。

### 6.3 往年优秀论文是否进入参考文献

本次对照的 2015-2021、2024-2025 年论文用于学习写作结构，不建议仅因为借鉴了章节组织就放入当前 Q2 的参考文献。只有正文实际使用了某篇论文的模型、数据、定理或实质观点，才应正式引用。

### 6.4 参考文献格式

建议采用顺序编码制，并按竞赛模板统一为 GB/T 7714 风格。示例：

```text
[1] ZHAO S, ZELAZO D. Bearing rigidity and almost global bearing-only formation stabilization[J]. IEEE Transactions on Automatic Control, 2016, 61(5): 1255-1268.
```

正文首次出现相应理论判断时标 `[1]`。同一文献后续继续使用同一编号，不要重复生成新编号。

## 10. 写作中最容易犯的错误

- 把 FY11/FY15 写成原题已经指定无偏差；
- 写“如 50 m”时忘记说明它只是 $d^\ast$ 的一个例子；
- 用内部目标坐标冒充无人机在线获得的绝对坐标；
- 把四参考机的六个角误写成来自多个接收机的汇总；
- 把同机留出角称为独立外部验证；
- 把三个参考点“通常够用”写成“一定唯一”；
- 把一阶谱半径为零写成两轮非线性精确收敛；
- 只报告 704/704，通过而隐藏压力域 2 个失败；

- 手工抄写正式数字，造成摘要、表格和 JSON 不一致；
- 为了显得高级，加入未使用的刚性控制律、遗传算法或随机优化；
