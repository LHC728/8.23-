## 2. 文献决策问题的综合结论

### LDQ-1：三架已知发射机能否保证 Q1(1) 唯一定位？

**证据链：**

- I4 从完整 P3P 解分类说明：三个已知控制点和三条已配对观察射线仍可能产生多个物理解或奇异解。
- C5 在特定控制点构型和观察区域下另行推导唯一性条件，反向证明“具有三点观测”本身不是唯一性的充分条件。
- I1 进一步说明角约束网络的唯一性取决于角可固定性与锚点几何，而非简单的方程数量。

**综合判断：CHALLENGE + CONFIRM。**

Q1(1) 不能从“三个发射机”直接宣称唯一定位。后续模型必须先生成全部可行候选，再利用题面明确允许的信息筛选，并给出共线、对称、镜像或分支合并等退化判据。

**迁移边界：** P3P 是三维相机位姿问题；当前题是二维、接收机处的两两夹角问题。只迁移“有限候选—唯一性条件—退化审计”的结构，不迁移 P3P 四次方程、姿态变量、具体解数或唯一性区域公式。

### LDQ-2：怎样定义“有效定位”？

**证据链：**

- I1 用角可固定性区分“拥有局部角约束”和“构型被唯一确定”。
- I5 说明没有公共全局坐标时仍能处理相对方向网络，但内部坐标只是表达规范，不是新增观测。
- C2 表明纯方位观测数量足够时仍可能因方位不变、站址或共线几何退化而不可观测。
- C4 给出直观反例：相同方位约束可能允许整体漂移或不同队形，需合适的锚点和约束结构才能固定。

**综合判断：CONFIRM。**

当前题中的“有效定位”至少应包含三层含义：

1. 在题面许可的信息下能够构造非空候选集；
2. 候选在题面允许的等价变换之外唯一，或能由明确先验唯一筛出；
3. 几何不处于退化或近退化状态，微小角扰动不会导致不可接受的分支跳变或误差放大。

这一定义不需要无人机知道全局坐标、距离或绝对朝向。为论文计算而建立的坐标系属于内部规范，不能写成现实接收机的已知信息。

### LDQ-3：Q1(2) 的匿名信号是否必须单独建模？

**证据链：**

- I3 明确把匿名相对方位分解为几何配置候选和离散身份关联，而不是把身份未知当成测量噪声。
- C3 显示错误方位组合会制造虚假交点；粗筛后再做细关联能把组合识别与连续定位分开。

**综合判断：CONFIRM + INSPIRE。**

Q1(2) 必须引入有限离散匹配变量。建议的结构顺序是：

`发射机组合/排列候选 → 每个候选下的几何位置候选 → 题面一致性检验 → 联合残差或可辨识性排序`。

若候选规模小，应优先完整枚举并证明覆盖，而不是直接引入随机搜索或复杂关联算法。

**迁移边界：** I3 的运动、惯性和贝叶斯尺度信息，以及 C3 的高斯误差、虚警率、最大似然门限，均无题面授权。当前题的“信号编号未知”也不等同于文献中的“多个运动目标来源未知”，关联方程必须重新建立。

### LDQ-4：怎样选择发射机并识别误差放大的几何？

**证据链：**

- C2 给出纯方位动态模型中的多类不可观测几何，证明退化来自结构而非求解器性能。
- C1 与 I6 均说明角误差会通过观测几何放大为位置偏差；改变解算器不能消除劣质几何提供的信息缺失。
- I2 说明约束边的数量与约束图是否刚性不是同一件事；选择局部约束需追求独立性而非简单凑数。
- C6 表明误差结论应按输入误差源和控制点几何分别验证。

**综合判断：CORRECT。**

发射机选择目标不应只是“数量达到上限”，而应优先排除共线、近共线、角度过小、约束重复及对称导致的候选混淆。具体几何指标尚未冻结，但后续必须同时考察：候选唯一性、局部灵敏度、最坏方向误差以及与匿名编号的可区分性。

**迁移边界：** 文献中的绝对 AOA、观测站坐标、运动轨迹、Fisher 信息、TLS 权重或 Gaussian 方差不能直接成为本题参数。只有在本题观测方程建立后，才能从其 Jacobian 或角残差重新定义条件指标。

### LDQ-5：Q2 如何从圆形特例推广到锥形一般编队？

**证据链：**

- I1 以角约束图和锚点讨论一般网络的可固定性。
- I2 从方位刚性说明局部方向约束通常仍保留平移、尺度等自由度，须由额外条件消除。
- I5 展示从局部三角方向关系组织一般网络定位的方式。
- C4 的理论与实机实验共同说明：方位约束本身可能不能唯一确定队形，Leader/锚点选取和约束图结构会改变唯一性。

**综合判断：CHALLENGE + INSPIRE。**

Q2 不是把圆周参数方程替换为锥形坐标即可。应先把理想编队表示为带编号节点和允许观测关系的约束图，再回答：

1. 哪些节点可作为题面许可的无偏差发射锚点；
2. 每个待调整节点实际能接收哪些夹角观测；
3. 这些局部约束能否在消除题面已固定的平移、旋转、尺度自由度后唯一确定目标位置；
4. 多节点调整后，原先作为参照的节点是否仍可靠。

**迁移边界：** 本题没有相对方位单位向量、Leader 绝对位置、连续动力学、邻机通信或控制输入。方位刚性和 Lyapunov 控制只能提供结构语言与升级方向，不能直接作为 Q2 的模型或收敛证明。

### LDQ-6：怎样验证算法没有偷用信息且结论不是模型内部自证？

**证据链：**

- I6 用偏差和均方误差比较不同估计器，支持统计重复而非单次示例。
- C1 比较多个解算器和误差条件，说明算法优劣依赖噪声与几何场景。
- C3 使用重复 Monte-Carlo 检验关联正确率，提示匿名识别必须报告错误匹配概率或成功率。
- C4 同时使用稳定性证明、实机实验和对照控制器，提供“理论—实验—基线比较”的独立验证结构。
- C6 将理论误差推导、统计分析和直接仿真分开，避免由同一目标函数生成数据又验证自己。

**综合判断：CONFIRM。**

后续至少建立四层验证：

1. **几何回代：** 用估计位置重新生成所有允许观测角，检查角残差；
2. **候选覆盖：** 小规模时用完整枚举或独立几何构造核对是否漏解；
3. **扰动试验：** 分别扰动测量夹角、允许存在偏差的发射机位置和初始编队，不把多类误差混成一个参数；
4. **策略级验证：** 报告每轮调整后的全编队误差、最坏个体误差、错误关联率、迭代次数与失败场景，并与最简单可行 Baseline 对照。

验证器可以读取仿真中的真实坐标来计算赛后误差，但定位或调整算法的决策输入不得读取真实距离、绝对位置、未来状态或其他隐藏信息。

## 4. 对当前路线的约束，而非模型冻结

### 已被证据支持，后续必须执行

1. Q1(1) 输出候选解并证明筛选规则，不默认唯一。
2. Q1(2) 单列匿名编号变量，并对全部允许组合保证覆盖。
3. Q1(3) 的发射机选择同时考虑可辨识性、几何灵敏度和编号区分度。
4. Q2 先建立一般编队的约束图、锚点和自由度审计，再设计调整机制。
5. 所有问题均以题面许可的角观测回代验证，并报告退化与失败情况。

### 目前只有升级依据，尚不能直接采用

- 加权/总体最小二乘：只有在角噪声模型或经验方差有来源时才有必要。
- Fisher 信息、条件数或 Jacobian 指标：须先由当前两两夹角观测方程推导。
- 方位刚性、角可固定性：须改写为当前“发射—接收角色受限”的约束图后重新证明。
- 最大似然或贝叶斯关联：只有在给出概率模型且简单枚举不足时才升级。
- 连续编队控制与 Lyapunov 稳定性：只有题目真正需要连续动力学时才考虑；当前不可据此替代离散调整设计。

## 5. 信息防火墙

下列量即使在文献中常用，也不得作为当前无人机现实决策输入：

- 发射机或接收机之间的距离；
- 绝对方位或公共全局朝向；
- 无人机真实绝对位置、未来状态或真实误差；
- 题面未提供的运动学、惯性、速度、时差、频差或通信信息；
- 未经说明的 Gaussian 分布、测角方差、虚警率、检测率和关联门限；
- 相机内参、像点坐标或 P3P 的三维姿态变量。

允许在论文与程序内部选取坐标系表达理想编队，也允许仿真评估器读取真值计算误差；但必须把“算法可用信息”和“赛后评估信息”分开记录。

### 最终使用纪律

- 核心建模论证优先引用 A 类文献，并逐条写明迁移边界。
- B 类文献只在解释背景、误差验证或补充置信度时使用。
- 若后续路线没有使用某篇 B 类文献所支持的机制，则不必为了“文献数量”强行引用。
- 任何文献都不能覆盖题面证据；当前题的观测方程、唯一性判据和调整策略仍须独立推导。
