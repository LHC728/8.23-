# Stage 1 - 问题地图

## 0. 阅读边界与状态

本阶段仅读取 B题.pdf、AGENTS.md、CURRENT_STATE.md；未读取任何历年经验文件、2023.md、网页或论文资料。未遇到污染信息。

## 1. 一句话问题本质

在没有距离、没有共同全局方位基准的纯两两夹角观测下，判断偏差接收机何时可被几何定位；再将该局部定位能力组织为分轮次的编队恢复方案。

题面定义的观测是：接收机到任意两架发射机的连线之间的夹角。它没有直接给出距离、统一罗盘下的单信号方位角、绝对位置或其他无人机当前坐标。

## 2. 解释用记号（不是模型承诺）

无人机同高度飞行，故为平面问题。

- p_i：第 i 架无人机在某一调整时刻的实际平面位置。
- p_i^*：第 i 架无人机在内部编队坐标中的理想位置。
- 发射机集合为 T，接收机 r 不属于 T。对 i,j 属于 T，接收机观测 theta_ij^(r)=angle(p_i-p_r,p_j-p_r)。
- 内部坐标系的原点、旋转和无物理尺度时的尺度均只是计算规范，不是接收机多获得的传感信息。
- 仅当题目明确某发射机“位置无偏差”时，才可将其实际位置视作等于规定理想位置。

## 4. 信息账本

### 4.1 共同信息边界

| 类别 | 题目授予/可安全使用 | 题目未授予/禁止偷用 |

### 4.3 坐标与编号边界说明

1. Q1(1) 中发射机编号全已知；Q1(2) 中除 FY00、FY01 外，信号源编号在推断完成前均为隐变量。
2. 表 1 用于赛题实例重建和验证；“仅根据接收到的方向信息”禁止把它当作机载实时坐标数据。
3. “编号固定、相对位置关系保持不变”可安全理解为成员和顺序关系，不能理解为对当前受扰坐标的直接测量。
4. 锚定一个数学坐标系只是去除坐标规范自由度，不增加物理观测。

## 5. 数学抽象（先不贴算法名称）

| 方面 | 题目中的结构 |
|---|---|
| 研究对象 | 带编号平面无人机编队，在小位置扰动下间歇式被动观测和调整。 |
| 几何对象 | Q1 的正九边形加圆心；Q2 的锥形/三角格点图；发射点、接收点、发射机对在接收机处张成的角。 |
| 状态 | 实际位置 p_i；是否已被认证为可信的位置状态；可能未固定的目标姿态/相位；Q1(2) 的信号源编号匹配。 |
| 观测 | 接收机处的无符号两两夹角 theta_ij^(r)。 |
| 未知变量 | 接收机坐标、偏差、匿名信号源编号、反射/顺序分支，以及未固定时的整体姿态。 |
| 控制变量 | Q1(3)、Q2 的逐轮发射机集合、顺序、移动节点和目标位置。 |
| 不变量/对称 | 两两夹角对平移、旋转、反射和共同缩放不变；Q1(3) 半径 100 m 与 Q2 物理间距给出尺度。正九边形的旋转/反射对称会被编号和锚点削弱；锥形格点也可能保留镜像/图自同构。 |
| 可辨识性 | 两个已知发射机仅给出一条定夹角轨迹，不能孤立接收机；三架编号已知且不退化的发射机可能足够，但须检查有限分支。Q1(2) 加入编号匹配不确定性。 |
| 多解和退化 | 定夹角轨迹可多交；无符号角可镜像；匿名匹配可多解。退化包括射线重合或近重合、共线、夹角接近 0 或 pi、锚点高对称、例外接收机位置、未校正发射机被误作锚点。 |

| 问题 | 数学结构分类 |
|---|---|
| Q1(1) | 平面几何定位、非线性参数识别、有限分支可行性/唯一性。 |
| Q1(2) | 几何定位加离散—连续联合识别、最小信息量。 |
| Q1(3) | 重复定位、顺序决策/控制、受限发射机集合设计、误差认证与有限轮恢复。 |
| Q2 | 一般编队约束实现、图/格点结构、分阶段控制、可观测性/可辨识性。 |

## 7. 核心数学困难

1. **无距离、无共同方位下的可观测性。** 两个已知信号只留下定夹角的一维轨迹；须证明更多角度在何种不退化条件下能唯一确定位置，并区分坐标约定和真实测量。
2. **几何和身份联合歧义。** Q1(2) 的匿名信号不能直接转为锚点坐标。最小信号数必须同时消除连续位置自由度、离散匹配和对称分支，不能仅以方程数判断。
3. **移动锚点造成的循环依赖。** Q1(3) 中外围发射机起初也可能偏差。未经证明可靠的发射机若被当作准确锚点，便会预设结论；必须按轮次建立可信锚点并规避退化选择。

Q2 的附加困难是圆心、半径和旋转结构不再存在，需要以共线、等间距和邻接约束恢复锥形格点，同时保证足够的非退化发射几何。

## 8. 题意歧义登记

### P0：不解决就阻塞路线

未发现。纯夹角观测、Q1(1)-(2) 的无偏差发射机前提和 Q1(3) 的发射机数量上限足以进入下一阶段。

### P1：会改变主要数学结构

当前没有阻塞性 P1。

Q1(3) 的“某个圆周”与紧邻的“圆心加半径 100 m 圆周”要求并存。工作解释为最终圆为以 FY00 为圆心、半径 100 m 的圆；若编号理想相位未被题面固定，则整体旋转可作为规范自由度。应在后续记录自由相位解释的敏感性，但不阻塞路线。

### P2：影响参数、实现或结果

- “有效定位”究竟指无噪声下一般唯一、理想点附近局部唯一，还是有噪声的稳健定位，须在后续给出操作性定义。
- 题面未说明匿名单个信号是否具有稳定本地标签/顺序。保守处理应使用无序的完整两两夹角配置；更强假设须明示。
- “略有偏差”无偏差上界和噪声规律，可用于局部分支选择，不能虚构为数值阈值。
- Q2 的“如 50 m”是等间距例示；一般设计应以间距 d 参数化。
- Q1(3) 的发射机数量限制没有在 Q2 重复，不能强加给 Q2，除非作为可选节能扩展。

### P3：主要影响表达

- 表 1 的 0-9 与 FY00-FY09 自然对应。
- “相对位置关系保持不变”应取成员和顺序关系的解释；若理解为当前相对向量精确不变，会与位置偏差矛盾。
- 图形画法方向是内部坐标约定；除非编号或锚点选择消除它，旋转/反射不是被实际观测到的全球方向。

## 11. 用户后续题意裁决（覆盖早期歧义登记）

本节是 Stage 5 后的正式补充，优先级高于第 8 节的早期歧义状态：

1. **禁止跨机夹角上报。** 某个夹角只能由测得它的接收机保存，并用于该接收机自己的动作与本机验收；不得转发给别机，也不得汇总到集中控制器参与动作计算。固定收发时序、编号和预装目标角不属于角上报。
2. **Q2 的“如 50 m”只是例示。** Q2 只要求指定直线上的相邻间距相等；共同尺度属于允许的相似规范，不要求恢复 50 m。

由此，Q1(1)、Q1(2) 的单接收机定位前端不变；Q1(3)、Q2 的任何执行路线都必须通过严格本地信息 Gate。当前有效替代路线见 `opening/06_INNOVATION_AND_ROUTES.md` 第 16 节。
